# Chrome Web Store English listing draft

## Name

GradWiser for arXiv

## Category and default language

Education; English.

## Summary from package

Open arXiv papers directly in GradWiser, with English or Chinese selected from your browser language.

## Description

Less copying. More understanding.

GradWiser for arXiv adds an "AI Chat with Paper" link to arXiv abstract pages and recognized arXiv results on Google Search. One click opens the paper's public abstract page in GradWiser in a new tab, connecting paper discovery with further reading.

Website: https://gradwiser.com

Key features

- On arXiv: find the link at the top of the Access Paper list.
- On Google Search: open recognized arXiv papers using a compact link beside the result title, without replacing the original link.
- Preserve explicit versions: when a source link specifies a paper version, open that version.
- English and Chinese: the browser's preferred language determines the link text and destination language.

How to use

1. Install the extension and visit an arXiv abstract page or search for arXiv papers on www.google.com.
2. Click "AI Chat with Paper" beside the paper.
3. View the public abstract in GradWiser and continue with the website's reading and AI chat features.

Clicking the link only opens the abstract page; it does not automatically send an AI request. Public abstracts do not require sign-in. Conditions for using AI chat and other website features are determined by GradWiser.

Privacy and supported pages

The extension identifies supported paper links locally. It does not collect search queries, surrounding page text, or account information, save reading history, or use telemetry. It does not send page data to GradWiser before you click.

After clicking, you visit the GradWiser website, whose data handling is covered by its privacy policy.

Supported pages are HTTPS abstract pages on arxiv.org and www.arxiv.org, and recognized arXiv links in www.google.com search results. The extension does not inject into PDF viewers. Some Google layouts or opaque redirect links may not be recognized.

GradWiser for arXiv is provided by GradWiser and is not affiliated with or endorsed by arXiv or Google.
